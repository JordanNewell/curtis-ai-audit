Every AI action in your vault leaves a receipt.

Curtis AI Audit is a local-first audit trail for AI agent activity in your Obsidian vault. Every agent action gets an append-only markdown receipt — plain files, no database, stored in the vault you already own.

Install the plugin File a receipt from anything GitHub ↗

● Everything lives in your vault as markdown. No accounts, no uploads, no telemetry.

what you get

Receipts you can read — and parse

One audit.v1 block per agent action: who, what, when, model, duration, tokens, status — plus a rendered human summary. Readable in Obsidian, parseable by anything.

Audit/ledger/ YYYY-MM-DD.md

Append-only per-day ledgers. The envelope is the receipt as canonical JSON; the body is the summary. Open a day's shard like any note — metadata only, tool input content is never recorded.

Audit/digest.md — the rolling digest

Counts, statuses, tokens, durations, a per-day breakdown, errors. Rewritten on demand — the ledgers are the source of truth, the digest is a view.

OM-1 inbox any agent can append to

External agents drop a message into Messenger/audit/inbox.md; the plugin polls with cursor semantics, rejects junk, dedupes redeliveries. The messenger plugin is not required — the inbox is just a file.

Verify — integrity without crypto

Detects malformed blocks, duplicate ids and sequences, reordered shards, and per-agent sequence gaps — deletions leave holes. No cryptography, no false promises.

install

Two installs, depending on who's writing

The plugin reads, verifies, and digests. The writer lets anything on your machine file receipts — no Obsidian needed.

01 the plugin

From a release: download main.js, manifest.json, and styles.css into <vault>/.obsidian/plugins/curtis-ai-audit/, then enable it in Obsidian (Settings → Community plugins). Not in the community directory; BRAT can track this repo for updates. Requires Obsidian 1.13.0+.

02 the receipt writer

From a checkout, one line puts a curtis-audit command on your PATH:

node install.mjs

After that: … | curtis-audit --agent my-agent --inbox …

agents

File a receipt from anything

Any shell, any agent, any device that can append to a file — the whole integration is one dependency-free line:

# one-off, from a checkout
echo '{"action":"inference","summary":"Nightly digest run"}' | node bin/curtis-audit-file.mjs \
  --agent research-agent --model gemini-2.5-pro \
  --inbox "$HOME/vault/Messenger/audit/inbox.md"

# after `node install.mjs`
echo '{"action":"inference","summary":"Nightly digest run"}' | curtis-audit \
  --agent research-agent --model gemini-2.5-pro \
  --inbox "$HOME/vault/Messenger/audit/inbox.md"

In-Obsidian plugins skip the bus with the direct API — and Install agent audit hooks writes vault-scoped configs so Claude Code and OpenCode file their own receipts; Codex and Gemini get manual recipes. Full recipes: INTEGRATION.md.

A journal, not a forensic system

Deliberate honesty: Curtis AI Audit is an accountability journal for the casual, accidental, and lazy cases — someone spending thirty seconds doctoring a markdown file defeats it. Tamper-evidence and retention enforcement are the next tier up and are not pretended here. The full statement of what is and isn't built: SPEC §8, the upgrade path (deliberately unbuilt).
